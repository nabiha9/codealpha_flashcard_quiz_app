# Flashcard Quiz App

A Flutter app for studying with flashcards. Each card shows a question on the
front and the answer on the back, and you can add, edit and delete your own cards.

## Features
- Question on the front with a "Show Answer" button
- "Next" and "Previous" buttons to move between cards
- Add, edit and delete flashcards
- Cards saved on the device, so they persist after closing the app
- Clean, minimal UI

## How to run
flutter pub get
flutter run -d chrome
